# Free-only staging

Contributors can run the [build and test checks](BUILD_AND_TEST.md) locally and review the results for their pull request in the [Portal repository](https://github.com/DruHustle/onesa-portal). Use disposable test data. Do not enter customer records, payment details or production credentials in a staging test.

The release owner selects the isolated staging environment and confirms that its usage is covered by the available allowance. A change that requires a paid service or an overage needs explicit budget approval. Ask the release owner for the current setup and verification procedure. [Onesa Internal Documents](https://docs.internal.onesa.eu) is the designated location for restricted operations guidance.

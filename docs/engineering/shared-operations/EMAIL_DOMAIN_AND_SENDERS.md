# Onesa email domain and senders

Onesa uses the visible sending domain `onesa.eu`. Each product identifies itself in the sender name and address. The [Portal repository](https://github.com/DruHustle/onesa-portal) maintains this shared convention. Each product team verifies its own delivery before enabling a sender.

## Product senders

| Product | Product notifications | Operational alerts |
| --- | --- | --- |
| Smart Logistics | notifications-logistics@onesa.eu | alerts-logistics@onesa.eu |
| Smart Farmer | notifications-farmer@onesa.eu | alerts-farmer@onesa.eu |
| Smart Factory | notifications-factory@onesa.eu | alerts-factory@onesa.eu |
| Onesa Robot | notifications-robot@onesa.eu | alerts-robot@onesa.eu |
| Onesa Drone | notifications-drone@onesa.eu | alerts-drone@onesa.eu |
| PasoFi | notifications-pasofi@onesa.eu | alerts-pasofi@onesa.eu |
| Onesa Portal | notifications-portal@onesa.eu | alerts-portal@onesa.eu |
| Onesa AI | notifications-ai@onesa.eu | alerts-ai@onesa.eu |

Product notifications cover normal system messages. Operational alerts identify events that need attention. These addresses identify senders and do not establish whether a mailbox accepts replies. Account access is shared across enabled Onesa products.

Authorized operators can obtain sender configuration and delivery verification procedures through [Onesa Internal Documents](https://docs.internal.onesa.eu).

# Staging environment configuration

Staging is an isolated place to test the Portal with synthetic data. Pull request checks run without access to deployment credentials. A maintainer can review the check results in the [Portal repository](https://github.com/DruHustle/onesa-portal).

Ask the release owner for the approved staging configuration and access verification procedure. [Onesa Internal Documents](https://docs.internal.onesa.eu) is the designated location for restricted operations guidance. Record the result of a configuration check in the restricted release record. Keep credential values out of issues, build logs and screenshots.

# Staging environment configuration

Staging is an isolated place to test the Portal with synthetic data. Pull request checks run without access to deployment credentials. A maintainer can review the check results in the [Portal repository](https://github.com/DruHustle/onesa-portal).

Use [Onesa Internal Documents](https://docs.internal.onesa.eu) for the approved staging configuration and the procedure for verifying access. Record the result of a configuration check in the restricted release record. Keep credential values out of issues, build logs and screenshots.

# Branch protection and recovery

The [Portal repository](https://github.com/DruHustle/onesa-portal) promotes changes through development, staging and main. Use a pull request against the intended branch, resolve review findings and verify the required checks on the revision being merged. The [release checklist](../../../RELEASE_CHECKLIST.md) records the evidence needed for a release.

Changes to protection rules and emergency recovery require the repository owner's authorization. Authorized maintainers can obtain the current recovery procedure through [Onesa Internal Documents](https://docs.internal.onesa.eu).
